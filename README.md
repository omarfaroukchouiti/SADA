# SADA — صدى

منصة إسلامية مجانية بالعربية (RTL) للقرآن الكريم: قراءة وتصفّح وتدبّر واستماع وبحث، مع طبقة API مملوكة للتطبيق.

> **Phase 1 — Core Quran experience.** المراحل اللاحقة (استيراد التلاوات المحلية، التفسير/الترجمة الموثّقة، المحتوى الإضافي، الأدوات) لم تُنفّذ بعد.

## المصادر

- **النص القرآني المعتمد:** [Tanzil Project](https://tanzil.net) — إصدار Uthmani v1.1، ملف حرفي غير معدّل مع checksum وعدّاديت تحقق (114 سورة / 6236 آية). الإسناد ظاهر في الواجهة.
- **بيانات مساعدة (UmmahAPI):** أسماء السور، الججز، التلاوات، التفسير، الترجمات والبحث في الترجمات. تُعرض دائمًا مع اسم المصدر، ولم تُعتبر تراخيصها مُثبتة بعد.

كل استدعاءات المزوّد الخارجي تتم من الخادم فقط عبر `src/lib/ummah.ts`، ولا تُستخدم مفاتيح أو أسرار في المتصفح.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:3000>.

أو للإنتاج:

```bash
npm run build
npm run start
```

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local` قبل التشغيل. لا توجد أسرار مطلوبة حاليًا؛ كل المتغيرات اختيارية بقيم افتراضية آمنة:

| المتغير | الافتراضي | الاستخدام |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | `http://localhost:3000` | الرابط العام في `metadataBase`؛ ضعه على رابط النشر الفعلي. |
| `UMMAHAPI_BASE_URL` | `https://ummahapi.com/api` | عنوان مزوّد البيانات المساعد، يُقرأ جانب الخادم فقط. |
| `SADA_BASE` | `http://localhost:3000` | عنوان الاختبار في `scripts/smoke.mjs` للتطوير فقط. |

لا يوجد مفتاح UmmahAPI مُدمج بعد؛ توثيق المزوّد يذكر مفتاحًا اختياريًا لرفع حدّ الطلبات لكنه لا يوضّح طريقة تمريره إلى بقية نقاط النهاية، ولن نخترع طريقة غير موثّقة.

## الأوامر

| الأمر | الوصف |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run start` | تشغيل البناء |

## البنية

```text
src/app                  صفحات App Router و SADA-owned API routes
src/components           مكوّنات الواجهة (القارئ، الفهرس، الصوت، التفسير، البحث)
src/lib/quran-data.ts    التحميل المحلي لنص Tanzil والبحث المشتق
src/lib/ummah.ts         محوّل UmmahAPI مع timeout وتخزين مؤقت و provenance
data/quran               نص Tanzil الأصلي + البيانات المشتقة + manifest
scripts                  بناء البيانات وفحص المسارات
```
